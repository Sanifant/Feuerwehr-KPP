# Security Policy

## Kommunaler Einsatzrahmen

Diese Anwendung ist fuer den Einsatz im kommunalen Umfeld der Feuerwehr vorgesehen.
Sicherheitsanforderungen orientieren sich an oeffentlichen Betriebsumgebungen mit erhoehtem Schutzbedarf.

## Sicherheitsgrundsätze

- Least-Privilege für Benutzer und technische Konten
- Protokollierung sicherheitsrelevanter Ereignisse
- Zeitnahe Einspielung von Sicherheitsupdates
- Trennung von Entwicklungs-, Test- und Produktivumgebungen
- Verschlüsselung von Datenübertragung und sensitiven Daten

## Supported Versions

Aktiv gepflegt wird die jeweils aktuelle Hauptentwicklung auf dem Standard-Branch.

## Reporting a Vulnerability

Bitte melde Sicherheitslücken verantwortungsvoll und nicht öffentlich.

1. Eröffne kein öffentliches Issue mit Exploit-Details.
2. Sende die Meldung an die Maintainer über einen privaten Kanal.
3. Beschreibe Reproduktion, Auswirkung und betroffene Versionen.

## Response Process

- Eingangsbestätigung: so schnell wie möglich
- Triage und Risiko-Bewertung: nach Eingang
- Fix und Veröffentlichung: priorisiert nach Schweregrad

## Disclosure

Nach Bereitstellung eines Fixes kann eine koordinierte Offenlegung erfolgen.

## Hinweise fuer Betreiber

- Regelmässige Sicherheitsprüfung der Abhängigkeiten durchführen
- Zugriffsrechte periodisch rezertifizieren
- Betriebsprotokolle revisionssicher aufbewahren
